# 审查清单

## 正确性

- [ ] 每个分支都有对应测试或明确说明。
- [ ] 空值、空集合、缺字段的处理一致。
- [ ] 边界：0、负数、最大值、超长、重复。
- [ ] 时间：时区、格式、夏令时、跨天。
- [ ] 数值：浮点精度、货币单位、溢出。
- [ ] 并发：共享状态、锁顺序、幂等。
- [ ] 资源：连接、文件、锁在异常路径也能释放。
- [ ] 错误路径：超时、部分失败、重试后仍失败。

## 安全

- [ ] 拼接 SQL/命令/HTML 的地方使用参数化或转义。
- [ ] 权限校验在服务端，不依赖前端隐藏。
- [ ] 日志不打印密码、token、身份证、完整手机号。
- [ ] 不把密钥、内网地址、个人绝对路径提交进仓库。
- [ ] 反序列化输入有类型与大小限制。
- [ ] 新增依赖来自可信源，版本固定。

## 兼容

- [ ] 接口新增字段可选，删除字段有迁移计划。
- [ ] 数据库变更可回滚，旧数据可读。
- [ ] 配置默认值在旧环境成立。
- [ ] 旧客户端不会被新行为破坏。

## 可维护

- [ ] 命名表达意图，不用 `data`、`temp`、`handle2`。
- [ ] 单个函数职责单一，嵌套不超过三层。
- [ ] 没有复制粘贴后改一半的重复逻辑。
- [ ] 没有注释掉的旧实现与调试输出。
- [ ] 没有为假想需求提前抽象。

## 测试

- [ ] 新增逻辑至少一条直接覆盖。
- [ ] 断言结果，不依赖实现细节。
- [ ] 错误路径断言错误类型或关键消息。
- [ ] 没有无原因 skip、没有把断言改松。
