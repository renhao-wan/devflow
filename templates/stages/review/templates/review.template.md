## 升级判断核对

- 轻量功能的实际 diff 是否命中硬触发（依赖、公共接口/契约、数据结构/迁移、安全边界、不可逆、规模）：否 / 是 / 不适用
- 轻量修复的实际 diff 是否命中硬触发（根因跨 >2 文件、公共契约、数据结构/迁移、依赖、不可逆、规模）：否 / 是 / 不适用
- 轻量修复的安全、数据、认证/权限/并发风险是否已标记 `review: required`：是 / 不适用
- 命中时是否已写 `## 升级判断` 并升级：是 / 否（否即阻断）
- 计数口径：排除 `docs/devflow/**`、测试文件、lockfile 与生成物
